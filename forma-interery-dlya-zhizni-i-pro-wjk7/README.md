# Forma — концепция первого экрана

Повторена композиция присланного референса: фото на весь экран, шапка поверх фото, три светлые карточки справа, крупный заголовок слева внизу, текст и кнопки справа, скруглённый переход к следующему блоку. Широкая сетка намеренно повторяет референс пользователя.

Десктоп: 1920×1080. Мобильный макет: 375×1180, PNG/JPG в масштабе 2×. Это дизайн-концепция, меню и кнопки служат визуальными обозначениями будущих действий.
